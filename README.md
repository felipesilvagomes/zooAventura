# 🦁 ZooAventura

**Explore. Descubra. Preserve.**

O ZooAventura é um aplicativo educativo desenvolvido com React Native e Expo, com o objetivo de aproximar os usuários do mundo animal de maneira divertida e interativa.

## 🌿 Sobre o projeto

Por meio de diferentes territórios, os usuários podem conhecer espécies de animais, descobrir curiosidades e aprender sobre seus habitats, alimentação e características.

## 🐾 Funcionalidades

- Cadastro e login de usuários.
- Acesso ao aplicativo como visitante.
- Exploração de diferentes territórios.
- Catálogo de animais.
- Informações e curiosidades sobre as espécies.
- Interface visual temática e intuitiva.

## 💻 Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- React Navigation

## 🎯 Objetivo

Incentivar o conhecimento sobre os animais, a biodiversidade e a importância da preservação da natureza.

## 👨‍💻 Desenvolvimento

Projeto acadêmico desenvolvido como parte das atividades do curso técnico da ETEC.
